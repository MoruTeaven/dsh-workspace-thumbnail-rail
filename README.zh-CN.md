# DSH 工作区缩略图栏

[English](https://github.com/MoruTeaven/dsh-workspace-thumbnail-rail/blob/master/README.md) | 简体中文

给 DeepSeek Harness（DSH）的每个工作区设置一张缩略图，并在侧栏与对话区之间加一条竖排的工作区缩略图栏——像 VS Code 那样，**左边是工作区，右边是对话**。

## 功能

- **为工作区设置缩略图**：右键任意工作区缩略图即可从本机选一张图片，自动居中裁剪为正方形并压缩后保存。
- **竖排工作区栏**：所有工作区在侧栏与对话区之间纵向排列，布局跟 VS Code 左侧资源管理器一致。
- **单击切换**：点击缩略图直接切到该工作区的对话。
- **右键菜单**：设置 / 移除缩略图、移除此工作区、隐藏缩略图栏。
- **宽度可调**：拖拽栏底部的手柄即可改变宽度，也可整体隐藏。
- **多标签页同步**：在一个页面设置缩略图，其它已打开的 DSH 页面会立即生效。
- **会话标题过滤**：在会话栏顶部输入关键词，列表按标题即时筛选，无需等待。
- **会话内容搜索**：点会话栏的搜索按钮，调用宿主自身的消息索引，可以按对话内容找到会话，并显示命中的摘要片段，点击结果直接打开。
- **重命名会话**：右键会话行选择「重命名」，直接在原位上修改标题。
- **复制会话 ID**：右键会话行选择「复制会话 ID」。
- **置顶会话**：右键会话行选择「置顶」，置顶的会话排在列表最前，与宿主的顺序一致（宿主不支持时该入口不显示）。
- **归档视图**：点会话栏的归档按钮浏览已归档的会话，并可逐条恢复。
- **重命名工作区**：右键工作区方块选择「重命名」，直接在原位上修改标题；与其它工作区重名会被拒绝。
- **分支会话**：右键会话行选择「分支此会话」，从最近一轮完成的内容开一个分支。
- **调整会话顺序**：拖拽会话行到新位置即可；置顶会话不参与排序，因为置顶顺序由宿主自己决定。
- **添加工作区**：点工作区栏顶部的「+」按钮，在应用内浏览目录、新建文件夹，然后选「选择此目录」把它加为工作区。

## 安装

```bash
# 在 DSH 的插件管理中安装，或手动放入插件目录
pnpm install
pnpm run build
```

## 使用

1. 右键点击缩略图栏中的任意工作区方块。
2. 选择「设置缩略图」，在弹出的文件选择器中挑一张图片。
3. 图片会被居中裁剪成 128×128 的缩略图并保存；未设置缩略图的工作区显示文件夹图标。

## 说明

- 缩略图保存在浏览器的本地存储中，不上传到任何服务器。
- 「移除此工作区」只会取消 DSH 中的工作区注册，**不会删除目录、文件或任何会话记录**。
- 本插件是一个预发布开发版（`0.1.0-dev.1`），功能可能继续调整。
